# Hybrid Deep Learning Approach for Kidney Stone Prediction

## Overview
This academic project explores kidney stone image classification using Convolutional Neural Networks (CNN), Vision Transformers (ViT), and a hybrid ensemble approach.

## Objectives
- Preprocess kidney images.
- Train CNN and Vision Transformer models.
- Combine predictions using a hybrid ensemble approach.
- Evaluate model performance using test-set predictions.

## Technologies
- Python
- Google Colab
- TensorFlow / Deep Learning
- Convolutional Neural Network (CNN)
- Vision Transformer (ViT)
- Ensemble Learning
